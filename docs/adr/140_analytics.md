# 140. Загруженность залов

**Статус:** принято.

## Решение
- `[Authorize(Roles = "admin")]` → `403` для остальных.
- Параметры: `from` и `to` — даты `yyyy-MM-dd` ([100](100_time.md)), `to >= from`, `to` включительно.
- Один SQL-запрос: занятия за период `starts_at >= from 00:00 UTC AND starts_at < (to + 1 день) 00:00 UTC`, при необходимости фильтр `room_id`. Группировка по `(starts_at AT TIME ZONE 'UTC')::date` и `room_id`:
  - `classesCount` — `COUNT(*)`;
  - `totalCapacity` — `SUM(capacity)`;
  - `bookedSeats` — сумма мест активных броней этих занятий.
- Отменённые занятия отсекает существующий глобальный фильтр запросов, отменённые брони — условие `status = 'active'`.
- Сортировка: дата, затем `room_id`. Строки только для дней и залов, где были занятия. Несуществующий зал даёт пустой список.
- Использует индекс `classes (starts_at, id)` из [130](130_schedule.md).
